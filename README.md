# Tetris (Incremental Build)

This repository contains a new TypeScript + Vite Tetris project built in small milestones.

## Setup

```bash
npm install
```

## Run locally

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Lint / format

```bash
npm run lint
npm run format
```

## Current milestone scope

- Project scaffold with Vite + TypeScript.
- Minimal UI: canvas plus tiny status panel.
- Pure game-logic helpers with unit tests for rotation, collision, and line clears.
